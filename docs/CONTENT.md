# Content Guide

All content is in `src/content/data.ts`. Edit it there; no component changes needed.

| Field | What to change |
|---|---|
| `profile.name / role / tagline / about` | Your identity and pitch |
| `profile.rotating` | Titles shown in the typewriter |
| `profile.stats` | Numbers shown in About (animated) |
| `profile.email / socials` | Contact links |
| `skills` | Groups and items |
| `projects` | title, desc, tags, `link` (live), `repo` |
| `experience` | role, org, period, bullet points |

## Tips
- Keep project descriptions to one sentence with a measurable result
- 4-6 projects, strongest first
- 2-3 bullets per job, starting with a verb and including a number

## Placeholders to replace
Everything is placeholder: email `roshan@example.com`, social URLs, company names, and all stats.
