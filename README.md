# Roshan Khatru — Portfolio

Vite + React + TypeScript + Tailwind v4 + Framer Motion + React Three Fiber.

## Run
```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # output in dist/
npm run preview
```

## Edit content
Everything lives in `src/content/data.ts`.
